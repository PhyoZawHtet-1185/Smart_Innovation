# Smart Innovation School

## 起動
index.html をブラウザで開いてください。
VS Codeなら Live Server を使うと確認しやすいです。

## ページ
- index.html：ホーム
- experience.html：体験
- events.html：イベント
- about.html：施設について
- contact.html：予約・お問い合わせ
- sitemap.html：サイトマップ
- style.css：全体のデザイン
- script.js：Action
- assets/：背景・イラスト

## 主なAction
1. ページ間のリンク移動
2. スマホ用ハンバーガーメニュー
3. イベントカテゴリーのフィルター
4. 体験内容のポップアップ
5. 予約フォームの入力チェックと受付表示
6. レスポンシブ対応

※予約フォームは学校課題用のフロントエンドデモです。実際の予約データはサーバーへ送信しません。
